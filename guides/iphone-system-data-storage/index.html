iPhone System Data storage: what it is and how to reduce it

Updated 2026-11-20. By Krosz Inc. Menu names can differ slightly between iOS versions.

Short answer: System Data is storage used by caches, logs, temporary files, voices and other items iOS manages. You cannot delete it directly. It usually shrinks after a restart, clearing Safari website data, removing heavy apps, and keeping iOS updated. In older iOS versions the same category was called Other.

What is System Data on iPhone?

System Data (earlier called Other) is a catch-all group in Settings › General › iPhone Storage. It includes things that are not apps, photos, media or the iOS system itself: caches from apps and Safari, temporary and log files, downloaded Siri voices and language assets, streaming caches, and some update files. Apple does not list every item, so the exact contents differ by phone.

It is normal for System Data to be several GB. It becomes a problem when it grows to tens of GB, or when the storage screen is slow to update.

Why does it get so large?

  • Streaming and downloads. Music, video and podcast apps cache content. Heavy streaming builds up large caches.
  • Safari and app caches. Browsing history, website data and app caches add up over time.
  • Large message history. Some message data is counted outside the Messages group.
  • Failed or partial updates. A half-finished iOS or app update can leave temporary files behind.
  • Almost-full storage. When the phone is nearly full, it can show inflated numbers until it finishes cleaning up.

How to reduce System Data

  1. Restart the iPhone. iOS clears some temporary files on restart. Check the storage screen again after a few minutes.
  2. Clear Safari data. Go to Settings › Safari › Clear History and Website Data. On iOS 18 it is under Settings › Apps › Safari. This signs you out of websites.
  3. Offload or delete heavy apps. Tap an app in iPhone Storage. If it shows a large Documents & Data figure, deleting and reinstalling it clears that cache. Offloading alone keeps the data.
  4. Trim downloaded media. Remove offline music, podcasts and videos you no longer use.
  5. Update iOS. Updates can clear old files and fix storage reporting bugs. You need free space to install them.
  6. Back up, erase and restore. This is the strongest option and clears most System Data, but only use it with a complete backup.

What does not work

There is no menu to delete System Data directly. Apps that promise to clear it in one tap usually clear only their own cache, or remove photos and files you could have chosen yourself. Be careful with any tool that asks for payment to remove System Data. What a cleaner can do honestly is find big files you control, such as duplicate photos, screenshots and large videos. Common questions

Is "Other" the same as System Data?

Yes, in practice. Older iOS versions labelled this group Other. Newer versions split the bar into iOS and System Data.

Is it safe to clear System Data?

The steps above only remove temporary data. Restarting, clearing Safari website data and offloading apps do not delete your photos or messages.

Why did System Data grow after an iOS update?

An update can leave temporary files for a while. Restart the phone and check again after a day. If it stays high, clear Safari data and review heavy apps.

How big should System Data be?

There is no single correct size. A few GB is common. If it takes up a large share of your storage and keeps growing, work through the steps above.
